# TechLab Pro

App móvil para el registro y gestión de equipos en laboratorios.

## Características
- Registro de equipos con validación de código (`XX00XX`).
- Adjunto de fotografías usando la galería nativa de Android.
- Guardado local de datos con Room DB.
- Interfaz moderna desarrollada en Jetpack Compose (Material 3).
- Arquitectura MVVM.
